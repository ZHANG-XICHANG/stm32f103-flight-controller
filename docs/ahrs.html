03 · Attitude estimation

姿態估測（AHRS）

每 6 ms 讀一次 MPU6050 的角速度與加速度，經過前處理後交給 Seb Madgwick 的 Fusion 函式庫，以四元數積分陀螺儀、用加速度計修正傾角，最後轉成 Roll / Pitch / Yaw 供 PID 使用。

本頁重點

  • 流程：LPF / Kalman → FusionRemap → FusionBias → FusionAhrsUpdateNoMagnetometer → FusionQuaternionToEuler。
  • 無磁力計：Roll / Pitch 由重力修正；Yaw 只靠陀螺積分，開機時歸零、長時間會漂移。
  • 推算 陀螺低通（α = 0.15）在 166.7 Hz 下截止頻率約 4.3 Hz，進入角速度內環前已有明顯相位落後，與實驗中的 4 Hz 振盪有關。

3.2前處理濾波

陀螺：一階低通

y[k] = 0.15·x[k] + 0.85·y[k−1]

推算 以 dt = 6 ms 換算：截止頻率 fc = −ln(0.85) / (2π·0.006) ≈ 4.3 Hz。在 4 Hz 時增益 0.73、相位落後約 39°。

加速度：純量 Kalman（每軸獨立）

P⁻ = P + Q；K = P⁻/(P⁻+R)；x̂ += K(z − x̂)

推算 Q = 0.001、R = 0.534 時穩態增益 K ≈ 0.042，相當於 α ≈ 0.042 的指數平均，截止約 1.1 Hz。加速度只用來提供重力方向，較重的平滑影響的是傾角修正速度。

3.3Fusion AHRS 設定與原理

Fusion 是互補濾波器形式的 AHRS：以陀螺儀角速度積分四元數，並把「量到的重力方向」與「估計的重力方向」之間的誤差，乘上增益後加回角速度。

ω' = ω + gain · eacc （eacc：加速度與估計重力的叉積誤差） q ← normalize( q + ½ · q ⊗ (0, ω') · dt )
依據
參數值意義
sampleRate166.7 Hz由任務週期換算（1000 / 6）
conventionNWUX 北 / 前、Y 西 / 左、Z 上
gain0.5加速度修正權重；開機前 3 秒由 10 線性降到 0.5（Fusion startup）

3.5四元數轉歐拉角（Fusion 公式）

roll = atan2( y·z + w·x , w² + z² − ½ ) pitch = asin ( 2·(w·y − x·z) ) yaw = atan2( x·y + w·z , w² + x² − ½ )
依據

用四元數做積分可以避免歐拉角在 pitch = ±90° 時的萬向鎖；只有輸出給 PID 時才轉成歐拉角。四旋翼正常飛行時 Roll / Pitch 在 ±10° 設定範圍內（搖桿映射，見控制），遠離奇異點。

3.6符號約定（NWU、右手定則）

角度旋轉軸正值代表
Roll+X（機頭）左側抬起、右側下沉
Pitch+Y（左）機頭向下
Yaw+Z（上）俯視逆時針轉（機頭往左）

推算 由右手定則與 NWU 定義推得，可用上方 3D 模型的預設按鈕驗證。sensor_alignment = FusionRemapAlignmentPXPYPZ 表示 IMU 軸被假設與機體軸完全一致，安裝方向必須配合 。

3.7限制與觀察

  • 無磁力計：Yaw 開機時歸零（startup 期間 FusionAhrsSetHeading(0)），之後只靠陀螺積分，會隨時間漂移；目前控制只用 Yaw 角速度，不受影響。
  • IMU 讀取失敗時保留上一筆姿態直接返回 ，PID 仍以舊值計算。
  • PID 使用的角速度經過 4.3 Hz 低通；Fusion 內部也使用同一個濾波後的角速度積分姿態，所以兩個迴路都承受這段相位落後。
  • 感測器約 500 Hz 更新，但每 6 ms 只讀一次，未在讀取前做抗混疊；高頻振動可能折疊進低頻（見研究延伸）。
