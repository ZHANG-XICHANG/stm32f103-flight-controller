04 · Control

控制系統

Roll 與 Pitch 使用「角度外環 → 角速度內環」串級 PID；Yaw 只有角速度 PI。三軸輸出以 PWM 修正量（µs）的形式進入 X 型混控，再限制在 1100–1940 µs 送到 ESC。

本頁重點

  • 串級結構讓內環先壓住角速度擾動，外環只需處理較慢的角度誤差；兩環都在同一個 6 ms 週期內依序計算。
  • 目前 Roll/Pitch 的 Ki = 0，實際是 PD 控制；內環 D 項採量測微分加 10 Hz 低通。
  • PID 本身沒有輸出限幅與積分抗飽和，限幅只發生在混控之後。

4.3PID 實作細節

為何內環用量測微分

外環輸出（內環目標）每 6 ms 都可能跳動；若對誤差微分，目標的跳變會被放大成 D 項尖峰。改用 −d(measure)/dt 只對機體真實的角速度變化反應，再加 10 Hz 低通壓低陀螺雜訊。

首次取樣不產生尖峰

initialized == 0 時把微分設為 0，只記錄基準值，避免開機第一個週期出現巨大的 D 項 。

串級的連接方式

PID_calc_chain() 先算外環，再把外環 output 直接寫入內環 desire，中間沒有角速度目標限幅 。

線上改參數

PidCommand_Apply() 在每輪 PID 前整組套用新增益；只有 Ki 改變時清除積分，D 歷史保留 。

4.5串級 PID 示意模擬（單軸 Roll）

◇ 模擬，不是實測　控制器逐行重現 com_pid.c；但機體以假設的二階模型表示（角加速度 = b × 修正量，經時間常數 τ 的一階馬達延遲），b 與 τ 未經系統識別。用途是說明「陀螺低通的相位落後會降低內環可用增益」，數值不能代表實機。

參數

滑鼠拖曳可放大時間軸、雙擊還原；觸控裝置點一下顯示數值。b 單位：°/s² 每 µs；修正量在 ±400 µs 處截斷以近似混控限幅。

模擬的定性結論與實驗一致：保留 α = 0.15 的陀螺低通時，提高內環 Kp 會出現約 3.5–4.5 Hz 的振盪或發散；拿掉低通後同樣的增益仍可收斂。實機上能否放寬低通，還需要評估馬達振動雜訊（見研究延伸）。

4.6狀態閘控

  • IDLE：開機狀態，馬達 1100 µs。解鎖條件：油門 < 10、Yaw/Pitch/Roll 皆在 490–510，且收到 power = 1 事件 。
  • NORMAL：唯一會混控的狀態；油門 < 10 時仍停機。
  • FAIL：失聯（1000 ms）時進入，停機；恢復連線後自動回到 NORMAL，不需要重新解鎖（README 已列為限制）。
  • FIX_HEIGHT：定高未實作，只停止馬達 。

4.7限制

  • PID 沒有輸出限幅、積分限幅或抗飽和；Yaw 的 Ki = 0.1 在長時間偏差下會持續累積。
  • 停機（IDLE / FAIL / 低油門）時 PID 仍持續計算，積分與微分狀態不會重置。
  • 混控限幅後沒有回饋給 PID；高油門時修正量可能被截掉，實際力矩比要求的小。
  • 設定值直接取搖桿，沒有斜率限制；外環 D 對誤差微分，搖桿快速變化會產生尖峰。
