研究延伸

本頁是尚未實作的規劃，每一項都從前面章節觀察到的現象出發，並寫明要怎麼驗證。目的是把「調到能飛」推進到「能說明為什麼這樣調、極限在哪裡」。

本頁重點

  • 核心問題：在 72 MHz、無 FPU 的 MCU 上，濾波延遲與控制頻寬如何取捨？
  • 先做系統識別取得機體模型，再以模型設計濾波與增益，最後用同一套實驗指標比較改善前後。
  • 所有提案都附驗證方法；沒有實驗數據前不宣稱改善效果。

7.2控制器改善

積分抗飽和與輸出限幅

在 PID_calc 加入輸出限幅、積分限幅與條件積分（clamping）或 back-calculation；停機時重置積分。

驗證：穩態偏差（例如重心偏移）下比較 Ki = 0 與 Ki > 0 的角度誤差與恢復時間。

混控飽和處理

修正量超出 1100–1940 µs 時，優先保留姿態力矩、犧牲總推力（airmode / desaturation），並把飽和狀態回饋給積分器。

驗證：高油門 + 擾動時記錄四路 PWM 是否觸頂與角度誤差。

設定值整形與前饋

搖桿目標加斜率限制或二階整形；外環 D 改為量測微分；可加入角速度前饋縮短反應時間。

驗證：搖桿步階的過衝、上升時間與 D 項尖峰大小。

增益排程

推力約與轉速平方成正比，ESC 指令與推力也非線性；不同油門下等效增益不同，可依油門調整內環增益。

驗證：先在推力台量「PWM → 推力」曲線，再比較不同油門下的振盪頻率。

Yaw 航向保持

yaw_pid 已存在但未接入；需定義目標航向、±180° 誤差環繞處理，且無磁力計時航向會漂移。

驗證：靜止 60 秒航向漂移量；加入磁力計前後比較。

進階控制器比較

以識別出的模型設計 LQR、ADRC 或 INDI（增量非線性動態反轉，對模型誤差較不敏感），與 PID 在相同指標下比較。

前提：先完成 7.4 系統識別；須評估 STM32F103 無 FPU 下的計算時間。

7.3濾波與取樣

  • 量化現有延遲：陀螺一階低通在 4 Hz 落後約 39°（推算）；再加上 D 項 10 Hz 低通、一個控制週期與馬達反應時間，建立內環的「延遲預算」。
  • 更高取樣率：利用 MPU6050 的 1 kHz 輸出（DLPF 設定配合）與 FIFO 或 DMA 讀取，內環以 500 Hz–1 kHz 執行，外環與 AHRS 可維持較低頻率。
  • 更好的濾波器：二階 Butterworth / biquad 取代一階低通，在同樣雜訊抑制下相位落後更小；針對馬達轉速頻率加陷波濾波（可由 FFT 動態追蹤）。
  • AHRS 與控制分開濾波：AHRS 積分可以用較輕的濾波，D 項另外使用較重的濾波，避免單一濾波器同時影響兩者。
  • 驗證方式：記錄未濾波陀螺的頻譜（需在遙測中增加欄位或板上高速記錄），找出馬達振動頻率；比較不同濾波的雜訊 RMS 與內環振盪頻率。

7.4系統識別

現有的示意模擬使用假設參數。要讓模擬有預測力，需要識別實機模型：

  1. 實驗平台：使用現有單軸測試架（照片），固定一軸只量 Roll。
  2. 激勵訊號：在內環輸出疊加 chirp（例如 0.5–20 Hz）或 PRBS，振幅小到不觸發限幅；遙測已能回傳修正量與角速度。
  3. 模型結構：以 ω̇ = b·u(t − τ_d) 加一階馬達延遲 τm 為起點，用頻率響應或 ARX / 輸出誤差法估計 b、τm、τd。
  4. 交叉驗證：用另一段記錄（例如擾動事件）比對模型預測與實測，回填到模擬器取代假設參數。
  5. 輔助量測：推力台量測 PWM → 推力與馬達時間常數；轉動慣量可由擺錘法量測。

限制：遙測經 ACK 回傳，覆蓋率 84–100%，且只有「最新快照」；識別實驗最好在飛控板上以 RAM 緩衝完整 166.7 Hz（或更高）資料，事後再傳回。

7.6安全機制強化

  • FAIL 恢復連線後要求重新解鎖，且油門須先回到最低。
  • IMU 校準失敗或連續讀取失敗時禁止解鎖 / 進入停機。
  • 加入獨立看門狗（IWDG），任務停滯時 MCU 重置並輸出停機脈寬。
  • remoteData 改為整包快照，避免讀到一半新、一半舊的搖桿值。
  • 控制封包加入序號，區分「收到舊封包」與「收到新封包」。
